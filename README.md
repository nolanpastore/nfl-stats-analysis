# NFL Stats Analysis Program

A Python data-analysis program created at the University of Dayton. The program analyzes NFL team performance from the 2003–2023 seasons using CSV data and generates comparison graphs.

## Features

- Retrieves team statistics by season
- Calculates and displays wins, losses, points, yards, touchdowns, and turnovers
- Creates league-wide comparison graphs
- Uses NFL team color styling in visualizations
- Analyzes trends with Pandas, Matplotlib, and Seaborn

## Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- CSV datasets

## How to run

1. Download or clone this repository.
2. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

3. Make sure `team_stats_2003_2023.csv` is in the same folder as `nfl_stats_analysis.py`.
4. Run:

   ```bash
   python nfl_stats_analysis.py
   ```
